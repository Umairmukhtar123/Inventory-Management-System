# Inventory Management System

## Project Overview
This is a C++ based Inventory Management System developed using Object-Oriented Programming (OOP) concepts. It helps manage product information and inventory records through a simple menu-driven interface.

## Features
- Add new products
- Display all products
- Search products by ID
- Search products by name
- Update product quantity and price
- Delete products
- Admin system management
- Backup confirmation

## OOP Concepts Used
- Classes and Objects
- Encapsulation
- Inheritance
- Function Overloading
- Getters and Setters
- Arrays of Objects

## Technologies Used
- Programming Language: C++
- Compiler/IDE: Dev-C++
- Concepts: Object-Oriented Programming

## Project File
- `InventoryManagementSystem.cpp`

## How to Run
1. Download or clone this repository.
2. Open the `.cpp` file in Dev-C++.
3. Compile and run the program.
4. Select an option from the menu.
